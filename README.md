Exam Preparation Academy & Readiness Tracker

Overview

Exam Preparation Academy & Readiness Tracker is a web-based academic management system designed to help students, faculty members, and administrators effectively monitor academic progress and examination readiness.

The system evaluates student performance using internal assessments, assignments, and test scores to generate a **Readiness Score** that reflects the student's preparation level for upcoming examinations. By combining performance tracking, syllabus completion monitoring, study planning, and risk analysis, the platform helps institutions improve student outcomes and academic success.



Features

Student Module

* Secure student login
* View personal profile and registration details
* Track syllabus completion percentage
* Monitor subject-wise academic progress
* View Readiness Score and exam preparation status
* Access internal marks and assessment records
* View previous year question papers
* Create and manage personalized study plans
* Receive notifications for pending study tasks
* Track study time using built-in timer functionality
* View weekly performance graphs and goal achievements

Faculty Module

* Secure faculty login
* View department-specific student records
* Upload and manage internal assessment marks
* Download student marks in Excel format
* Monitor student academic performance
* Identify and track at-risk students
* Access department-wise academic analytics
* Manage subject-related academic information

Admin Module

* Manage students, faculty members, and subjects
* Add, update, and remove student records
* Monitor institution-wide academic performance
* View total students, faculty members, and subjects
* Track overall readiness statistics
* Identify students requiring academic support
* Generate academic monitoring reports
* Maintain centralized system administration



Key Benefits

* Improves student exam readiness and preparation
* Helps faculty identify weak-performing students early
* Enables data-driven academic decision making
* Reduces manual effort in performance tracking
* Provides centralized academic monitoring
* Encourages consistent study habits and goal achievement

Installation

Clone the Repository

```bash
git clone https://github.com/yourusername/Exam-Readiness-Tracker.git
```

Navigate to Project Folder

```bash
cd Exam-Readiness-Tracker
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run the Application

```bash
python app.py
```

Open in Browser

```text
http://localhost:5000
```
